📚 Computer Architecture Basics

CPU

The CPU is the main processor of a computer. It executes instructions and performs calculations.

RAM

RAM temporarily stores data and programs that the CPU is currently using.

Motherboard

The motherboard connects the CPU, RAM, storage, GPU and other computer components.

Storage

Storage such as SSDs and HDDs keeps data even when the computer is turned off.

GPU

A GPU processes graphics and is especially useful for games, video editing and 3D applications.

Power Supply Unit

The PSU converts electrical power into suitable power for the computer's components.
